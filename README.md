# Proyecto Estudiantes

Sistema de gestión y registro de estudiantes desarrollado en Python con persistencia en JSON.

## Estructura del Proyecto
- `main.py`: Punto de entrada de la aplicación.
- `models.py`: Definición de modelos de datos.
- `views.py`: Interfaces y presentación en consola.
- `shared/`: Módulos compartidos, gestores y utilidades.
- `data/`: Almacenamiento local de datos (`estudiantes.json`).

## Requisitos
- Python 3.10 o superior

## Ejecución
```bash
python main.py
```
